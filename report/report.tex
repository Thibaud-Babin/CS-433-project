\section*{Summary}
We had to predict whether a person has coronary heart disease from their answers to the 2015 BRFSS health survey. We first implemented the six required linear methods in NumPy, cleaned the survey answers and chose the decision threshold that maximizes the F1 score. The best linear model, regularized logistic regression, reached a cross-validated F1 of $0.4290$. We then implemented gradient-boosted decision trees, which reached $0.4357$ and are used for our final submission.

\section{Task and Data}
Each sample is one survey respondent described by 321 answers, and the label (\texttt{MICHD}) says whether they were diagnosed with coronary heart disease \cite{brfss2015}. The training set has 328{,}135 samples and the test set 109{,}379. Only $8.8\%$ of the training labels are positive, so predicting ``healthy'' for everyone already gives $91\%$ accuracy. For this reason we focus on the F1 score of the positive class. All results below come from stratified 5-fold cross-validation, with the same folds for every model.

\section{Preprocessing (Linear Models)}
We applied the following steps, with every statistic computed on the training set only:
\begin{enumerate}
\item drop survey metadata (dates, weights, sequence numbers) and columns with more than $80\%$ missing values;
\item decode the special BRFSS codes: 88, 888 and 555 mean ``none'' ($\rightarrow 0$), 77, 99, 777 and 999 mean ``don't know'' or ``refused'' ($\rightarrow$ missing);
\item one-hot encode columns with at most 15 distinct values, with missing as its own category;
\item for the other columns, replace missing values by the median, add a missing indicator and clip to the $0.1\%$--$99.9\%$ quantiles;
\item remove columns that are linear combinations of others, standardize and add a bias column.
\end{enumerate}
This gives 371 features. We also tried a smaller set of 21 hand-picked risk factors \cite{xie2019building, teboulheart}.

\section{Models}
\textbf{Linear models.} We implemented least squares and ridge regression (normal equations), linear regression with gradient descent and SGD, and logistic regression with and without $\ell_2$ penalty. We tuned the hyperparameters on a small grid. The best one is regularized logistic regression ($\lambda=10^{-4}$, $\gamma=0.5$, 500 iterations).

\textbf{Gradient-boosted trees.} Linear models cannot combine features (e.g.\ ``old \emph{and} diabetic''), and trees usually work better on tabular data \cite{grinsztajn2022tree}. We therefore wrote our own gradient boosting in NumPy, in the style of XGBoost \cite{chen2016xgboost}. Each raw column is cut into 64 bins and missing values get their own bin, so this model needs none of the preprocessing above. We add trees of depth 3 one by one (learning rate 0.1), each trained on a random half of the rows and columns, and stop when the loss on a held-out $10\%$ of the training set stops improving. We removed the column \texttt{HAREHAB1} (cardiac rehabilitation): it is only asked to people who had a heart attack, so it gives away the label.

\textbf{Decision threshold.} With so few positives, the default threshold (probability 0.5) predicts almost nobody as sick. For each model we choose the threshold that gives the best F1 on the cross-validation predictions.

\section{Results}
Table~\ref{tab:models} shows the results. The boosted trees get the best F1, $0.4357$ ($\pm0.0028$ between folds), against $0.4290$ for regularized logistic regression. The features they use the most are general health, stroke, age, sex and diabetes. The linear models are all between $0.419$ and $0.429$, except SGD, which converges slowly.

The two choices that helped the most were using all features instead of the 21 selected ones ($0.4125 \rightarrow 0.4290$) and choosing the threshold (Figure~\ref{fig:threshold}): with the default threshold, F1 is only $0.233$.

\section{What Did Not Work}
We tried several ways to improve the trees, but none changed F1 by more than the noise between folds ($\pm0.003$): extra hand-made features (risk-factor counts, target encoding), a smaller learning rate, more bins, other models (additive models, random forests) and averaging several models (best $0.4373$). All these models make the same mistakes: their predictions are $95$--$99\%$ correlated. Keeping \texttt{HAREHAB1} would have given $0.444$, but only by leaking the label.

\section{Conclusion}
Our final model, gradient-boosted trees with a tuned threshold, reaches a cross-validated F1 of $0.4357$. As often in practice \cite{domingos2012few}, using all the data and choosing the threshold mattered more than the choice of model. Since many different attempts all stay around $0.436$, we think this is close to what can be predicted from these survey answers. \texttt{python run.py} reproduces our submission and \texttt{python run\_linear.py} the linear results.

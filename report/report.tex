\begin{abstract}
Early identification of individuals at risk of coronary heart disease is a valuable public-health goal. We build a binary classifier over the 2015 Behavioral Risk Factor Surveillance System (BRFSS) survey, predicting whether a respondent reports a diagnosed heart attack from 321 self-reported health and lifestyle questions. We implement six linear methods from scratch in NumPy, design a preprocessing pipeline (one-hot encoding, imputation, clipping, standardization), and select the decision threshold by maximizing the F1 score on out-of-fold predictions---a step made necessary by the $8.8\%$ positive class. The best model, regularized logistic regression trained on all features, reaches a five-fold cross-validated F1 score of $0.4290$, nearly doubling the F1 obtained with the default threshold.
\end{abstract}

\section{Introduction}
The task is a supervised binary classification problem: given the answers of a respondent to the 2015 BRFSS survey \cite{brfss2015}, predict the \texttt{MICHD} variable, which records whether the respondent has been diagnosed with coronary heart disease (myocardial infarction). The training set contains 328{,}135 samples described by 321 raw features and the test set 109{,}379 samples. Only $8.83\%$ of the training labels are positive, so accuracy is misleading---a trivial all-negative classifier scores $91\%$---and the task is evaluated with the F1 score, which balances precision and recall on the positive class.

Our contributions are (i) a NumPy-only implementation of six linear models, (ii) a preprocessing pipeline that turns raw survey answers into a standardized design matrix, and (iii) a threshold-selection procedure that maximizes F1 on out-of-fold predictions. We validate every choice with stratified five-fold cross-validation and report an ablation of the most impactful decisions.

\section{Data and Preprocessing}
The BRFSS 2015 data \cite{brfss2015} mixes continuous answers (BMI, age) and categorical answers (smoking status, income bracket) with survey metadata (weights, dates, sequence numbers). We drop all metadata and any column with more than $80\%$ missing values. BRFSS sentinel codes are decoded: values such as 88, 888 and 555 (``no such value'') and 77, 99, 777 and 999 (``don't know''/``refused'') are treated as missing. Columns with at most 15 distinct values are one-hot encoded (most frequent level as reference, rare categories merged into it, missing as its own indicator); continuous features are imputed with the training median, receive a missingness indicator, and are clipped to the $0.1\%$--$99.9\%$ training quantiles. Columns that are linear combinations of others are removed, all features are standardized to zero mean and unit variance using training statistics, and a bias column is appended. Labels are mapped from $\{-1,+1\}$ to $\{0,1\}$. The full pipeline yields 371 features.

As an ablation, we also consider a hand-picked set of 21 interpretable features (64 columns after one-hot encoding) motivated by the diabetes risk factors identified by Xie et al.\ \cite{xie2019building} and curated for this heart-disease task by Teboul \cite{teboulheart}.

\section{Methods}
We implement the six linear methods from scratch using only NumPy: least squares and ridge regression via the normal equations, linear regression with gradient descent and stochastic gradient descent, and logistic regression with and without $\ell_2$ regularization, trained by gradient descent on the logistic loss. Hyperparameters---regularization strength, step size and iteration count---are selected on a small grid with five-fold cross-validation; the best configuration is regularized logistic regression with $\lambda=10^{-4}$, step size $\gamma=0.5$ and 500 iterations.

Because the positive class is rare, thresholding scores at zero (probability 0.5) is suboptimal. For every model we compute out-of-fold scores with stratified five-fold cross-validation (seed 1) and choose the threshold that maximizes F1 on those scores. The same folds are used for all models, so comparisons are paired.

\section{Results}
The best model, regularized logistic regression ($\lambda=10^{-4}$, $\gamma=0.5$, 500 iterations) trained on all features, reaches a five-fold cross-validated F1 of $0.4290$ ($\pm0.0042$) with $0.8768$ accuracy and an F1-optimal threshold of $-1.3153$.

Figure~\ref{fig:threshold} shows F1 as a function of the decision threshold. The curve is strongly peaked: the naive threshold $t=0$ gives F1 $0.233$, whereas the optimum $t\approx-1.315$---predicting the positive class more often---gives $0.4290$. For imbalanced data the threshold is therefore a first-order hyperparameter.

Table~\ref{tab:models} compares representative models trained on all features. All well-behaved linear models cluster in a narrow band (F1 $0.419$--$0.429$), consistent with a weak, largely linear signal; SGD is the exception, converging slowly and noisily. Ablations: (i) using all 371 features instead of the selected 64-column subset raises F1 from $0.4125$ to $0.4290$, the single largest gain; (ii) $\ell_2$ regularization is nearly neutral ($0.4288$ to $0.4290$) but stabilizes the loss; and (iii) optimizing the threshold raises F1 from $0.233$ to $0.4290$.

\section{Discussion and Conclusion}
Regularized logistic regression on all features with an F1-optimized threshold reaches a five-fold cross-validated F1 of $0.4290$ on a noisy, self-reported survey where the linear baselines lie close to one another. The analysis shows that feature breadth and threshold selection matter more than the choice among linear models, consistent with the advice that data and evaluation often dominate the learner \cite{domingos2012few}. All results are reproducible: \texttt{python run.py} retrains the reported model and writes the AIcrowd submission. A limitation is that linear models cannot capture feature interactions; in the follow-up project we plan to explore non-linear and ensemble methods.
